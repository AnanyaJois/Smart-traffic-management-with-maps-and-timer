# 🚦 Smart Traffic Management System

A web-based smart traffic management system designed to help monitor and control traffic signals through an interactive dashboard. The system provides map-based traffic visualization, adjustable signal timers, and priority handling for emergency situations such as ambulances and VIP vehicles.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Python 3.9 or later
* pip
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/AnanyaJois/Smart-traffic-management-with-maps-and-timer.git
```

Navigate to the project directory:

```bash
cd Smart-traffic-management-with-maps-and-timer
```

### 2. Install Dependencies

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
python app.py
```

Open the local URL displayed by the application in your browser.

## 🧠 How It Works

The system provides a dashboard for managing traffic signals and monitoring traffic conditions.

```text
Traffic Data
     ↓
Interactive Dashboard
     ↓
Traffic Map
     ↓
Signal Monitoring
     ↓
Timer Adjustment
     ↓
Emergency / VIP Priority
     ↓
Updated Traffic Control
```

The administrator can view traffic locations, adjust signal timings, and provide priority to emergency or VIP vehicles when required.

---

## 🚑 Emergency Vehicle Priority

The system supports priority handling for emergency situations.

When an ambulance or other emergency vehicle needs priority, the traffic signal timing can be adjusted to help provide a clearer route.

This feature demonstrates how traffic management systems can dynamically respond to emergency requirements.
